# 05. Comments Tree

## Мета

Flat → nested через `Map` + рекурсію, пошук із збереженням батьків.

## Дані

`src/data/comments.ts` — 80 коментарів, 5 коренів, глибина 4. Це локальний фікстур на основі текстів DummyJSON, бо реальний API не має `parentId`.

## Що зробити

`buildTree(flat)`:

- корені — `parentId === null`;
- осиротілі вузли теж стають коренями;
- вузол не може бути батьком сам собі;
- порядок дітей як у вхідному масиві;
- без мутацій.

`countDescendants(node)` — усі рівні, без самого вузла.

`filterTree(nodes, query)`:

- вузол лишається, якщо збіг у ньому або в нащадку;
- якщо збіг у самому вузлі — лишається все піддерево;
- пошук по `text` і `author`, без урахування регістру;
- порожній запит — дерево без змін.

## Підказки

<details>
<summary>Підказка 1</summary>

Спочатку створи `Map<id, {...comment, children: []}>`, потім одним проходом розклади дітей.
</details>

<details>
<summary>Підказка 2</summary>

`filterTree` зручно писати через `flatMap`: якщо вузол збігся — `[node]`, інакше рекурсивно фільтруй дітей.
</details>

<details>
<summary>Підказка 3</summary>

Не забудь створити нові об'єкти вузлів при фільтрації, інакше зміниш оригінальне дерево.
</details>
