# 09. topKFrequent

## Мета

Порахувати частоти через `Map` і знайти top-k без повного сортування.

## Що зробити

`topKFrequent(nums, k)`:

- частота спадаюче;
- за рівної частоти — менше число першим;
- k = кількість унікальних — повернути всі;
- `k = 0` → `[]`;
- бажано bucket sort за частотою: `O(n)` + обробка бакетів.

## Підказки

<details>
<summary>Підказка 1</summary>

`Map<number, number>` для частот. Максимальна частота ≤ `nums.length`.
</details>

<details>
<summary>Підказка 2</summary>

Створи `buckets[count] = number[]`, іди від `nums.length` вниз, сортуй лише бакет, доки не набереш k.
</details>

<details>
<summary>Підказка 3</summary>

Якщо хочеш строго `O(n)`, замість сортування бакета можна використати quickselect, але для цієї задачі достатньо відсортувати бакет.
</details>

## Перевірка

```bash
npm test -- 09-top-k-frequent
```

## Дебаг

Натисни «Запустити бенчмарк» на 100 000 чисел. Порівняй з наївним варіантом через `sort` усіх унікальних значень. Перевір приклад `[4,4,5,5,6], k=2`.
